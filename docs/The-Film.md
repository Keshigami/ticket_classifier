# The film

`demo/film.mp4` is 90 seconds in four chapters, made for engineers and project managers who have ninety seconds.

1. **What it does** (0 to 17 s): a terminal prompt runs the project's real first command and the response becomes a printed object. Tags, priority, action: valid JSON, every time. Then the stake: Two of eight are urgent. Does the schema hold with no key?
2. **How it is built** (17 to 40 s): a paper model of the pipeline, stage by stage, with the reveal: Offline eval · models/metrics.json · the floor, the one line of code that matters, the API call and the tests.
3. **The proof** (40 to 68 s): the real app, recorded. Ticket #1: billing, as JSON An outage, then a feature request The raw JSON, and the badge: offline
4. **The answer** (68 to 90 s): 8/8, tickets back as valid JSON · offline, no key. And it ships. One limit: Offline says Low; the hand label says High. Then the prompt types `just setup && just up`.

`demo/film-60s.mp4` is the same without the proof chapter. `demo/demo.mp4` is the plain captioned walkthrough of the app.

Every number in the film comes from the project's own metrics, findings or a live response; nothing is drawn by hand. The film pipeline lives in the author's workspace, not in this repo.
